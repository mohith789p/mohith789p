### 🚀 Featured Projects

#### 🗺️ [codeAtlas](https://github.com/mohith789p/codeAtlas)
`Python` `FastAPI` `Vector Indexing` `Next.js` `TypeScript` `AST Parsing`

- **Challenge:** Standard lexical search and naive file splitting fail to capture structural syntax and multi-file dependencies in large codebases.
- **Solution:** Built a code intelligence engine using syntax-aware AST chunking and vector indexing to deliver grounded codebase walkthroughs and multi-hop repository question-answering with exact file and line-level citations.

#### 🎥 [YouTube-Q-A](https://github.com/mohith789p/YouTube-Q-A)
`Python` `Semantic Search` `Embeddings` `FastAPI` `Next.js` `Whisper / Subtitles`

- **Challenge:** Extracting answers from lengthy video transcripts without losing conversational context or generating unverified responses.
- **Solution:** Developed an end-to-end transcript retrieval system featuring overlapping temporal chunking, similarity ranking over dense embeddings, and citation grounding mapped directly to video timestamps.

#### 💬 [ai-chatbot-app](https://github.com/mohith789p/ai-chatbot-app)
`Next.js` `TypeScript` `Redis` `SSE Streaming` `Function Calling` `Gemini / Mistral`

- **Challenge:** Managing real-time response latency, context drift, and non-deterministic schema validation during extended conversational sessions.
- **Solution:** Implemented Server-Sent Events (SSE) for low-latency streaming output, combined with Redis sliding-window memory buffers and strict JSON schema function calling for predictable, production-grade responses.
